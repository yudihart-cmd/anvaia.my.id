Kebijakan Privasi

Aplikasi: DSI Klaim Engine · berlaku sejak 29 September 2026

Untuk siapa aplikasi ini

DSI Klaim Engine adalah alat pribadi milik Yudi Hartono untuk menyusun klaim penggantian biaya perjalanan dinasnya sendiri. Aplikasi ini tidak dibuka untuk umum dan hanya dipakai dengan akun Google milik pemiliknya.

Data yang dibaca

Dengan izin baca-saja Gmail (gmail.readonly), aplikasi hanya mengambil email berlabel Whoosh, Invoice, dan Reimburse, yaitu tiket, invoice, dan struk perjalanan. Email lain tidak diproses. Aplikasi tidak pernah mengirim, mengubah, atau menghapus email.

Cara data dipakai dan disimpan

  • Rincian transaksi (tanggal, merchant, nominal, rute) dicatat ke berkas laporan klaim milik pemilik di OneDrive.
  • Token akses disimpan terenkripsi di server pribadi pemilik, tidak di layanan pihak ketiga.
  • Isi bukti dapat dibaca oleh model bahasa (OpenAI) semata untuk mengekstrak rincian transaksi.
  • Data tidak dijual, tidak dipakai untuk iklan, dan tidak dibagikan ke pihak lain selain untuk mengajukan klaim atas permintaan pemilik.

Penggunaan data Google API

Penggunaan dan pemindahan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

Mencabut akses

Akses dapat dicabut kapan saja di myaccount.google.com/permissions.

English summary

DSI Klaim Engine is a private tool used only by its owner to prepare his own travel-expense claims. It requests read-only Gmail access, reads only messages labelled Whoosh, Invoice or Reimburse, and never sends, modifies or deletes email. Extracted transaction details are stored in the owner's own OneDrive; tokens are stored encrypted on the owner's private server. Data is not sold, used for advertising, or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
